# React Exam

A React + TypeScript admin dashboard for managing and viewing users.

## Features

* User list
* User details
* User statistics
* Client-side routing
* Responsive UI
* API data fetching with TanStack Query

## Tech Stack

* React
* TypeScript
* Vite
* React Router
* TanStack Query
* Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```

## Routes

| Route       | Description  |
| ----------- | ------------ |
| `/`         | Dashboard    |
| `/users`    | User list    |
| `/stats`    | Statistics   |
| `/user/:id` | User details |
